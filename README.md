# MVP 베이스볼 2003 PS2 한글패치

PS2 북미판 **MVP Baseball 2003 (SLUS-20650)**용 비공식 한국어 패치입니다. **메뉴·옵션·시즌·프랜차이즈·경기 HUD 등 게임 문자열**, **로딩 화면 그림 15장**, **선수 이름 전부**(실제 선수 DB와 신인·드래프트 이름 풀)를 한국어로 바꿨습니다. PCSX2용 **16:9 와이드 패치**도 함께 배포합니다. 현재 배포판은 **v1.4 (2026-11-06)**입니다.

[패치 다운로드](https://github.com/snake759494/mvp-baseball-2003-ps2-korean-patch/releases/latest) · [기술 설명](docs/TECHNICAL.md) · [재빌드](docs/BUILD.md) · [변경 기록](CHANGELOG.md) · [권리 안내](RIGHTS.md)

릴리즈 첨부 파일은 한글패치 **MVP_Baseball_2003_PS2_KO_v1.4.xdelta**와 와이드 패치 **SLUS-20650_926DD489.pnach**입니다. 저장소에는 제작 소스와 한국어 번역만 공개합니다. 원본·완성 디스크 이미지, 추출한 게임 파일, 영어 원문, 글꼴 파일, 외부 실행 파일은 포함하지 않습니다. GitHub가 자동으로 만드는 Source code ZIP/TAR는 저장소 소스를 압축한 것이며 게임 파일이 아닙니다.

## 게임 소개 및 대상 버전

『MVP Baseball 2003』은 EA Sports가 2003년에 낸 메이저리그 야구 게임입니다. 시범 경기, 시즌, 최대 120시즌 프랜차이즈, 홈런 쇼다운 등을 담고 있습니다.

이 패치는 **PS2 북미판 SLUS-20650의 DVD ISO**에만 적용됩니다. 파일 이름보다 아래 표의 크기와 해시가 일치하는지가 중요합니다.

## 패치 적용 방법

```powershell
Get-FileHash -Algorithm MD5 -LiteralPath '.\MVP Baseball 2003 (USA).iso'
```

위 표와 다르면 적용을 중단하세요. CHD, CSO, 압축 이미지에는 적용할 수 없습니다.

### xdelta UI 사용

1. 릴리즈에서 `MVP_Baseball_2003_PS2_KO_v1.4.xdelta`를 받습니다.
2. xdelta3 패치를 지원하는 도구에서 **Apply Patch** 기능을 엽니다.
3. **Patch**에는 xdelta 파일을, **Source File**에는 해시가 일치하는 원본 `.iso`를 선택합니다.
4. **Output File**에는 새 파일 이름을 지정합니다(예: `MVP Baseball 2003 (Korean).iso`).

xdelta는 호환성을 위해 압축·2차 압축·파일 경로 헤더 없이 만들었습니다. xdelta 자체는 [공식 프로젝트](https://github.com/jmacd/xdelta)를 참고하세요.

### 명령줄 사용

```powershell
.\xdelta3.exe -d -s '.\MVP Baseball 2003 (USA).iso' '.\MVP_Baseball_2003_PS2_KO_v1.4.xdelta' '.\MVP Baseball 2003 (Korean).iso'
```

원본판 세이브 스테이트는 쓰지 마세요. 메모리 카드 세이브는 원본판과 호환됩니다.


## 저메모리판 (Lite)

ARMSX2·AetherSX2/NetherSX2 같은 모바일 에뮬레이터에서 시작할 때 튕긴다면 **MVP_Baseball_2003_PS2_KO_v1.4_Lite.xdelta**를 쓰세요. 적용 방법은 일반판과 같습니다.

- 실행 파일(SLUS_206.50)을 전혀 고치지 않아 게임 CRC가 원본과 같은 `55493524`입니다. 와이드 패치는 **SLUS-20650_55493524.pnach**를 씁니다.
- 한글 폰트 텍스처를 512×256 이하로 줄였습니다. 폰트 묶음 크기는 일반판 약 950KB에서 약 230KB(원본 약 48KB)로 줄었습니다. 그 대신 한글 글자가 작습니다(11~13px).
- 선수 이름은 영문 그대로입니다(이름 한글화에는 실행 파일 수정이 필요해서).
- 메뉴·옵션·시즌·경기 HUD 번역과 로딩 화면 그림은 일반판과 같습니다.

## 16:9 와이드 패치 사용법 (PCSX2 2.x)

`SLUS-20650_926DD489.pnach`는 **한글패치를 적용한 ISO 전용**입니다. 한글패치가 실행파일을 고쳐 게임 CRC가 `55493524`에서 `926DD489`로 바뀌므로, PCSX2에 내장된 원본판 와이드 패치는 자동으로 적용되지 않습니다. 이 파일은 그 내장 패치(Arapapa 제작)를 한글판 CRC에 맞춰 옮긴 것입니다.

1. PCSX2에서 한글판 ISO를 한 번 부팅하고 종료합니다. 로그(도구 > 로그 창 보기)나 게임 목록 속성에서 CRC가 `926DD489`인지 확인합니다.
2. `SLUS-20650_926DD489.pnach`를 PCSX2 `patches` 폴더에 복사합니다. 파일 이름을 바꾸지 마세요.
   - 설치판 기본 위치: `문서\PCSX2\patches`
   - 포터블판: PCSX2 폴더 안의 `patches`
   - 정확한 위치는 설정 > 폴더에서 "패치" 항목으로 확인할 수 있습니다.
3. 게임 목록에서 MVP Baseball 2003을 우클릭하고 **속성 > 패치**를 엽니다. **Widescreen 16:9**에 체크합니다.
4. 같은 속성 창의 **그래픽 > 화면**에서 **화면비(Aspect Ratio)**를 **와이드스크린 (16:9)**으로 바꿉니다. 동영상도 16:9로 보려면 **FMV 화면비 전환**도 16:9로 둡니다. pnach의 `gsaspectratio=16:9` 줄 때문에 패치를 켜면 화면비가 자동으로 바뀌기도 합니다.
5. 게임을 시작하면 화면 위에 "1개의 게임 패치가 활성화되었습니다"가 뜹니다. 경기 화면의 3D 시야가 좌우로 넓어집니다.

주의
- 원본 북미판 ISO에는 이 파일이 필요 없습니다. PCSX2 내장 와이드 패치를 그대로 켜면 됩니다.
- 3D 경기 화면만 보정됩니다. 메뉴·HUD·글자 같은 2D 화면은 가로로 늘어나 보입니다.
- 패치가 목록에 없으면 파일 이름의 CRC(`926DD489`)와 실제 게임 CRC가 같은지, `patches` 폴더 위치가 맞는지 확인하세요.
- 와이드 패치를 끄려면 속성 > 패치에서 체크를 풀고 화면비를 4:3으로 되돌립니다.

## 한글화 범위

- 게임 문자열 표 `DATA/ENGLISH.LOC` 2,202개 중 1,933개: 메뉴·옵션·저장/불러오기·메모리 카드 안내, 시즌·프랜차이즈·토너먼트·홈런 쇼다운, 트레이드·계약·부상·드래프트 메시지, 기록 약어, 구종, 구장·팀 이름, 경기 HUD·일시 정지·교체·결과 메시지, 조작 설정, 선수 만들기
- 로딩 화면 그림 15장(조작법, "알고 계셨나요?", 프랜차이즈 팁, 구종표), 부팅 라이선스 화면
- 선수 이름 전부: 실제 선수 DB(이름·성 1,312개)와 신인·드래프트 이름 풀(2,001명). 외래어 표기법과 국내 중계 관례에 따라 표기
- 원문 유지: 곡명·밴드명(EA TRAX), 개발용 시험 문자열, 라인 스코어 R/H/E, 로고·동영상 속 글자, 경기 중 그림 글자(PRESS START, 홈런 더비 점수 라벨), 날짜 서수(25TH 등)

## 알려진 한계

- 감독 평점 등급 A는 기록 약어 A(보살)와 문자열을 공유해 영문으로 남겼습니다.
- 이름 칸 한도 때문에 긴 이름은 이름 5자·성 7자까지 들어갑니다.
- 와이드 패치는 3D 화면만 보정하며, 2D 화면은 가로로 늘어납니다.
- PCSX2에서 메인 메뉴, 바로 경기, 로딩 화면, 경기 HUD, 일시 정지·박스 스코어, 옵션, 프랜차이즈 주요 화면을 확인했습니다. 시즌·토너먼트·홈런 쇼다운 전 과정, 트레이드·드래프트·선수 만들기 세부 화면, 실기에서의 동작은 확인하지 못했습니다. 문제가 있으면 이슈로 알려 주세요.
