# 기술 설명

## 한글 표시 방식
1. LOC 문자열이 UTF-16이고 SFN 폰트 글리프 표가 16비트 코드를 이진 탐색하므로 **ELF 수정 없이**
   한글을 유니코드 그대로 넣고 폰트에 해당 코드의 글리프를 추가했다.
2. SFN(FNTS v0x16e): 헤더 0x80, 0x40/0x44에 1/텍스처폭·1/높이(float), 글리프표 뒤 커닝표, 4bpp 텍스처 + 팔레트 블록.
   텍스처는 폭 512~1024, 높이는 필요한 만큼(2의 거듭제곱 아님). 낱개 `DATA/FONTS/*.SFN`과 `FONTS.BIG`(게임이 실제로 읽음) 양쪽 갱신.
3. 서체: 원본 Tw Cen 계열과 가장 비슷한 고딕 **나눔스퀘어 네오**(본문 cBd, 제목·버튼 eHv, AU20B는 기울임).
   가장 작은 폰트(12~14px)도 판독이 충분해 갈무리체는 쓰지 않았다. 팝업/설명 폰트(TWC14·TWC16)는 줄 간격이 좁아 85% 크기.
4. 공유 문자열 분리: 구장 거리 라벨(LF/LC/C/RC/RF)이 포지션 약어와 같은 문자열이라 게임이 쓰지 않는
   시험 문자열 ID(11, 14982~14986)를 빌려 FEL 레이아웃(FRONTEND.BIG)이 가리키게 했다. **새 ID를 LOCI에 추가하면 표시되지 않는다.**
5. 로딩 화면: 1024x512 8bpp SSH. 글자 영역을 OpenCV inpaint로 지우고(은색 띠는 행별 보간) 한글을 그린 뒤 256색 재양자화.
6. 선수 이름: DB(`DATA/DATABASE.BIG`)의 이름은 1바이트 문자열이라 한글 음절을 2바이트로 넣는다
   (i = 코드 - 0xAC00 → 0x80 + (i >> 7), 0x80 + (i & 0x7F)). ELF(`SLUS_206.50`) 세 곳을 고쳐 해석한다:
   char*→UTF-16 복사 함수 0x5007D8, 포맷터 %s 경로 0x5013D0(위 함수 호출), 이름 머리글자("트. 글로스") 자르기 0x2FFA90(한글이면 2바이트에서 자름).
   이름 필드 한도: 이름 11바이트, 성 14바이트(한글 5·7자).
7. 폰트 메모리: 폰트가 약 1MB를 넘으면 경기 로딩이 멈춘다. 한글 글리프를 원본 글리프 블록 오른쪽 빈 곳부터 채우고
   텍스처 면적이 가장 작은 폭을 골라, 이름 글자를 더하고도 v1.0보다 작게 유지(약 950KB).
8. 디스크: 크기가 맞으면 제자리, 넘치면 이미지 끝에 붙이고 ISO9660·UDF 디렉터리 갱신.

## 16:9 와이드 패치 (PCSX2)
- `SLUS-20650_20A53021.pnach`: PCSX2 내장 와이드 패치(Arapapa, 원본 CRC 55493524)를 한글판 ELF CRC(20A53021)에 맞춰 옮긴 것.
- 2D 보정(선택): "Widescreen 2D image fix (experimental)" 패치를 켜면 메뉴·HUD 그림이 가로로 늘어나지 않습니다. 글자 출력 경로는 별도라 글자는 보정되지 않으므로 기본값은 꺼짐입니다.
  한글 패치가 ELF를 고쳐 CRC가 바뀌므로 내장 패치는 자동 적용되지 않는다. 패치 주소(0x4ECFA8 줌, 0x4ED038 시야각)는 한글 패치와 겹치지 않음.
- 설치: `문서\PCSX2\patches`에 복사 → 게임 속성 > 패치에서 "Widescreen 16:9" 켜기, 화면비 16:9.
- 3D 화면만 넓어지고 메뉴·HUD 같은 2D 그림은 가로로 늘어나 보인다.

## 주의
- `INGAME.BIG`(경기 중 레이아웃)은 재압축으로 크기가 늘면 경기 로딩이 멈춘다. 건드리지 않음.
- 감독 평점 등급 A는 기록 약어 A(보살)와 문자열을 공유해 영문 유지.

## 16:9 와이드 패치

- PCSX2 내장 와이드 패치(Arapapa, 원본 CRC `55493524`)의 두 줄을 한글판 ELF CRC `20A53021`용 pnach로 옮겼다.
  - `0x4ECFA8` `lui at,0x3F40`: 3D 줌 계수 1.0 → 0.75
  - `0x4ED038` `lui at,0x3FAB`: 시야각 계수 1.0 → 1.336
- 한글 패치가 ELF를 고치므로 CRC가 바뀌어 내장 패치가 자동으로 적용되지 않는다. 두 주소는 한글 패치가 고친 곳(0x2FFA90, 0x5007D8, 0x5013D0)과 겹치지 않는다.
- 2D(메뉴·HUD·글자)는 보정하지 않는다. 그림은 직교 투영 행렬로 그리지만 글자는 별도 경로로 그려서, 그림만 줄이면 글자와 어긋난다.
